# Кросс-компиляция в Alca

[English](cross-compilation_EN.md) | [Русский](cross-compilation_RU.md)

Alca собирает автономные исполняемые файлы без необходимости устанавливать инструментарий целевой ОС (cross-toolchain) на сборочной машине. Для сборки требуются только скомпилированные рантайм-стабы Alca.

## Структура исполняемого файла

```text
[рантайм-стаб целевой ОС] + [Alca payload] + [длина payload uint64] + [ALCA_EXEC_V2 сигнатура]
```

Рантайм-стаб представляет собой бинарник `cmd/alca`, скомпилированный под целевую ОС и архитектуру процессора. Он содержит виртуальную машину, интерпретатор и стандартную библиотеку. Полезная нагрузка (payload):
- Байткод VM по умолчанию (исходный текст не распространяется);
- Исходный код с импортированными модулями `.al` при явном указании флага `--source`, если программа подключает локальные файлы или использует динамические возможности интерпретатора.

Кроме того, внешние ресурсы проекта (файлы или каталоги) могут быть встроены в бинарник с помощью флага `--embed <path>`. Во время выполнения они доступны через модуль `use std.embed; embed.read("path")` или `embed.list()`.

Конверт полезной нагрузки версионирован и снабжен контрольной суммой SHA-256. Рантайм проверяет целостность перед декодированием. Поврежденный или обрезанный файл немедленно отклоняется с диагностической ошибкой.

## Сборка рантайм-стабов

Из корня репозитория (при установленном Go):

```bash
go run ./cmd/alca build-runtimes --out runtimes
```

Команда генерирует:

| Платформа | Файл рантайма |
| --- | --- |
| `linux/amd64` | `runtimes/alca-linux-amd64` |
| `linux/arm64` | `runtimes/alca-linux-arm64` |
| `darwin/amd64` | `runtimes/alca-darwin-amd64` |
| `darwin/arm64` | `runtimes/alca-darwin-arm64` |
| `windows/amd64` | `runtimes/alca-windows-amd64.exe` |
| `windows/arm64` | `runtimes/alca-windows-arm64.exe` |

Полезные опции:
```bash
--out <dir>          каталог вывода (по умолчанию: runtimes)
--targets a,b        список платформ, например linux/amd64,windows/arm64
--tags nodb          сборка рантайма без драйверов БД (легковесный бинарник)
```

## Сборка приложения под другую платформу

```bash
alca build app.al --target linux/amd64 -o app
alca build app.al --target windows/arm64 -o app.exe
```

Порядок поиска рантайм-стабов для целевой платформы:
1. `--runtime <файл>`
2. Переменная среды `$ALCA_RUNTIMES`
3. `<каталог бинарника alca>/runtimes`
4. `<каталог бинарника alca>`
5. `~/.alca/runtimes`
6. `./runtimes`

Команда `alca targets` выводит список доступных целевых платформ.

## Безопасность собранных приложений

Автономные приложения запускаются с теми же ограничениями песочницы, что и `alca run`. Файловая система, сеть и вызовы внешних процессов запрещены, если при запуске бинарника не переданы соответствующие флаги:

```bash
./app --allow-read=./data --allow-net=api.site.com input.txt
```
