Индекс пакетов Alca (APM) — это официальное хранилище программного обеспечения и менеджер пакетов для языка программирования Alca.

APM помогает вам находить, устанавливать и подключать модули, разработанные сообществом Alca. Все пакеты верифицируются контрольными суммами SHA-256 и разрешаются с фиксированием версий через apm.lock.

Авторы пакетов используют APM для быстрой и атомарной доставки исходного кода и скомпилированных артефактов (байткода VM и нативных динамических библиотек для Windows, Linux и macOS).

Быстрый старт:
# Создание нового пакета / New package
$ alca apm init --name mypkg --lib

# Добавление зависимости / Add dependency
$ alca apm add mathutils

# Публикация в реестр / Publish to registry
$ alca apm publish --registry http://91.92.34.94:9977
