# Alca (бывш. Bast)

Строго типизированный язык со скриптовым синтаксисом. Файлы: `.al`.

## Правила
- Каждый простой оператор заканчивается `;`. Блоки (`if/while/for/func/struct`) `;` не требуют.
- Типы статические и строгие: `x: int = 5;` или `x := 5;` (тип выводится и фиксируется). Неявных преобразований нет: `"a" + 5` — ошибка, нужен `string(5)`.
- `null` только в типах вида `T | null`; проверка `if x != null:` сужает тип.
- Условия только `bool` (нет «истинности»). `int / int` — целочисленное деление.
- Тип `json` — единственный динамический; чтобы использовать значение, его приводят: `int(j["a"])`.
- Проверка типов выполняется всегда: `run`, `build`, `test`, `check`.

## Команды
    alca run file.al            # VM по умолчанию; для функций, которые VM не умеет
                                # (ba/threads/tx/watch/mock/timeout, декораторы) — авто-откат на интерпретатор
    alca check file.al          # синтаксис + типы
    alca test file.al           # блоки test
    alca build file.al --target linux/amd64 -o app
    alca targets                # какие runtime установлены
    alca build-runtimes         # собрать runtime под все платформы (нужен Go, один раз)

## Кросс-компиляция
Результат сборки = runtime целевой платформы + сериализованный байткод (исходник не вкладывается).
Пользователю Go не нужен. Runtime собираются один раз: `make runtimes` (папка `runtimes/`),
далее `ALCA_RUNTIMES=./runtimes alca build app.al --target windows/arm64`.
Платформы: linux, darwin, windows × amd64, arm64.

## Сборка
    go build -o alca ./cmd/alca          # с SQLite/Postgres
    go build -tags nodb -o alca ./cmd/alca   # без драйверов БД (без сторонних модулей)
