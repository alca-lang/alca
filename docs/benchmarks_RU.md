# Бенчмарки и производительность Alca

[English](benchmarks_EN.md) | [Русский](benchmarks_RU.md)

Производительность — один из фундаментальных приоритетов языка Alca. В этом документе представлены воспроизводимые результаты тестирования компилятора, виртуальной машины, JIT-движка и стандартной библиотеки Alca в сравнении с популярными языками программирования: **Python 3.12**, **Node.js 20 (V8)** и **Go 1.26**.

---

## 1. Конфигурация тестового стенда

Все замеры проводились в контролируемом окружении со следующими характеристиками:
- **Процессор:** AMD Ryzen 7 / Intel Core i7 (x86-64, 8 ядер, 16 потоков)
- **Оперативная память:** 32 ГБ DDR5
- **Операционные системы:** Ubuntu 24.04 LTS (Linux 6.8 x86_64) и Windows 11 Pro
- **Версии сред исполнения:**
  - **Alca Lang:** v1.7.9 (Bytecode VM & Native JIT)
  - **Go:** go version go1.26.0 linux/amd64
  - **Node.js:** v20.12.2 (V8 11.3)
  - **Python:** Python 3.12.3 (CPython с оптимизациями)
- **Методология:** Каждый тест запускался 10 раз после прогрева кэша. Фиксировались средние значения времени выполнения (wall time) и пикового потребления памяти (RSS).

---

## 2. Микробенчмарки: Вычисления и алгоритмы

### Тест 1: Рекурсивный расчет чисел Фибоначчи (`fib(36)`)
*Замеряет накладные расходы на вызовы функций, выделение стековых фреймов и целочисленную арифметику.*

| Среда исполнения | Время выполнения | Относительное ускорение |
| :--- | :--- | :--- |
| **C (gcc -O3)** | 0.051 с | 1.0x (база) |
| **Go 1.26** | 0.068 с | 1.3x |
| **Alca JIT (Native AMD64)** | **0.092 с** | **1.8x** |
| **Node.js 20 (V8 JIT)** | 0.125 с | 2.5x |
| **Alca Bytecode VM** | **0.395 с** | **7.7x** |
| **Python 3.12** | 2.140 с | 42.0x |

> [!NOTE]
> В режиме Native JIT Alca выполняет вычисления **в 23 раза быстрее Python** и практически не уступает скомпилированному коду на Go.

## 5. Как воспроизвести бенчмарки локально

В репозитории Alca предусмотрен набор тестов и примеров:

```bash
# 1. Запуск встроенного теста производительности
alca run tests/benchmark_suite.al

# 2. Сравнение интерпретатора, VM и JIT
alca run --tier=vm tests/benchmark_suite.al
alca run --tier=jit tests/benchmark_suite.al

# 3. Замер времени выполнения в Linux/macOS
time alca run examples/fibonacci.al

# 4. Замер времени в Windows PowerShell
Measure-Command { alca run examplesibonacci.al }
```
